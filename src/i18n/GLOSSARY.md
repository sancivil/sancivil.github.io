# Terminology — English / Arabic / Kurdish (Sorani, `ckb`)

Use these terms everywhere so the three languages read as one product. Iraqi usage beats
textbook usage: people in Iraq say "إنفرتر" and "ئینڤێرتەر", not a literal translation.

Brand and product names stay in Latin script in every language: **Faraday, Peimar, PVGIS,
MPPT, model codes (OR10H560M, PSI-X1P6000-HY), units (W, kW, kWp, kWh, V, A, °C, mm, kg, %)**.
Digits are always Western (0–9). Wrap codes, numbers and units in an element with
`dir="ltr"` (the `.num` and `.mono` classes already isolate bidi) so "−0.25 %/°C" or
"1x6 (1)" never flips.

Tone in Arabic: Modern Standard Arabic, short sentences, no flowery marketing. Tone in Kurdish:
standard Sorani orthography (ڕ ڵ ۆ ێ ە), plain and direct. Both translations need a native
review by the client before launch; keep sentences simple to make that review fast.
